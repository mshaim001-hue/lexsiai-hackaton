## Где остановились

- 5.2–5.4. Нашли расхождение контекста при упаковке траектории в TRL. Подключили scoring по исходным ID каждого хода, tool observations в контексте и вне loss. Подтвердили реальный шаг GRPO с изменением LoRA.
- 5.5. A — модель без обучения, B — reward за успех, C — B со штрафом за невалидный вызов. После одного шага B и C получили побайтно одинаковые адаптеры: в train-группе штраф не сработал. В h0/103 инструмент подтвердил возврат, но агент выдал ещё один lookup_order вместо финала. См. artifacts/task-5-5/summary.json.
- 5.6. Контролируемый прогон подтвердил влияние LoRA dropout на rollout. При eval() на t0 три корректных финала и один повторный lookup_order после submit. Дополнительный штраф на этой группе только масштабирует центрированные награды и практически не меняет advantage. См. artifacts/task-5-6/dropout_check/summary.json.
- 5.7. Перед перезагрузкой в рабочей копии появились код run_grpo_b_steps.py и файлы бюджета/конфигурации в artifacts/task-5-7. На момент записи отчёта или адаптера там не было. Это незавершённый эксперимент. Проверь содержимое папки после восстановления. Если результат успел сохраниться, используй его как дополнительный результат.
